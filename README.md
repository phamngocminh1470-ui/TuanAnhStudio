## 🎯 Giới Thiệu Dự Án

**Examora AI** là công trình nghiên cứu Khoa học Kỹ thuật (KHKT) được phát triển nhằm giải quyết triệt để vấn đề "học cào bằng", thiếu cá nhân hóa trong việc ôn luyện môn Tiếng Anh THPT tại Việt Nam.

Hệ thống kết hợp các lý thuyết khoa học giáo dục đo lường tiên tiến cùng Trí tuệ nhân tạo (AI) hiện đại nhằm tạo ra lộ trình thích ứng riêng biệt cho từng học sinh.

### Các Trụ Cột Khoa Học & Công Nghệ Cốt Lõi:
1. **Mô hình Đo lường Giáo dục IRT (Item Response Theory) 2PL & 3PL:** Tự động ước lượng chỉ số năng lực người học ($\theta$) và độ khó câu hỏi ($b$), độ phân biệt ($a$), hệ số đoán lụi ($c$), giúp bài thi thích ứng từng câu hỏi theo thời gian thực.
2. **Thuật toán Lặp lại Ngắt quãng SuperMemo-2 (SM-2):** Tối ưu hóa đường cong lãng quên Ebbinghaus, tính toán chu kỳ ôn tập từ vựng ngắt quãng theo từng ngày.
3. **Mô hình Gia sư đối thoại Socrates AI:** Ứng dụng LLM theo phương pháp truy vấn gợi mở của Socrates — không đưa ra đáp án trực tiếp mà dẫn dắt học sinh tự tư duy và phát hiện lỗi sai.
4. **Hệ thống Đánh giá Phát âm 44 Âm vị Chuẩn Quốc tế (IPA):** Phân tích âm học giọng đọc, nhận diện lỗi sai chi tiết đến từng âm đơn và âm đôi.

## 🛠️ Kiến Trúc Hệ Thống (Tech Stack)

* **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti, PWA (Progressive Web App).
* **Backend:** Python FastAPI, Uvicorn, SQLite / PostgreSQL.
* **Mô hình Toán & AI:** 2PL/3PL IRT Estimation Engine, SuperMemo SM-2 Algorithm, Google Gemini Pro API / OpenAI LLM APIs, Web Speech Recognition / Whisper Audio Analysis.
* **Máy chủ & Triển khai:** Linux VPS (Ubuntu Server), Nginx Reverse Proxy, SSL/TLS Let's Encrypt, Cloudflare DNS.
